## Traps that have already cost time here

- **`ralpine submit` puts options before the script.** It did not until this round, and every
  `--dependency`, `--array` and `--export` was silently discarded. After submitting a chain,
  verify with `scontrol show job <id>` that `Dependency=` is set. A satisfied dependency
  correctly reads `(null)`.
- **`check_release --all` does not examine untracked files.** Stage a file before trusting a
  clean report on it.
- **Never compare across gene panels.** Check 1 runs on 14,121 genes, Check 2 on 12,368, rung 2
  on 8,759. A ratio between two rungs is only valid on one panel, and the rung-0 ceiling has to
  be pinned to the panel it denominates via `--panel-file`.
- **Validate a statistic before reporting it.** `tests/test_statistics_recover_known_answers.py`
  requires every reported statistic to recover a planted answer and return null on no signal.
  The recurring error is comparing an aggregate against a distribution of per-item values.
- **Report the full declared variant set**, via `scripts/report_variants.py`. Hand-written
  summaries here have dropped variants and omitted multiple-testing correction.
